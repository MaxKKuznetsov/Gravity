# examples — референсы и текстуры

Папка для **кастомизации внешнего вида** игры: образцы текстур, фото
и наброски. Агент и разработчик ориентируются на них при отрисовке
(Canvas 2D), но файлы **не подключаются в runtime сами по себе** —
их не импортируют из `src/`, пока явно не решите загрузить картинку.

## Содержимое

| Путь | Назначение |
|------|------------|
| `asteroids/` | Референсы формы и поверхности астероидов (`a1.jpg` … `a5.jpg`) |
| `crack/crack.jpeg` | Референс трещин на разрушенной планете (в игре — красные линии) |

## Как пользоваться

1. Положите новый референс в подходящую подпапку (или создайте свою).
2. Кратко опишите его в этой таблице.
3. При правках рендера (`src/render/…`) опирайтесь на картинку: цвет,
   характер линий, пятна — без обязательного пиксель-в-пиксель копирования.

Новые игровые ассеты, которые реально грузятся в браузере, лучше класть
отдельно (например в `public/`), а `examples/` оставлять справочником.
