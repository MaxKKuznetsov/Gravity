# Gravity — план работ

Стек: TypeScript + Vite + Canvas 2D, своя физика, гравитация по закону 1/r².
Каждый этап заканчивается игрой, которую можно запустить и потрогать.

Статусы: ⬜ не начат · 🔄 в работе · ✅ готов

## Этап 0. Подготовка окружения ✅
- Проверить, установлены ли Node.js (LTS, 20+) и git. **Если чего-то нет,
  спросить владельца перед установкой.**
  Итог: Node 20.18 не подошла свежим Vite 8, Vitest 5 и ESLint 10, поэтому
  с согласия владельца через nvm поставлена Node 24 (`.nvmrc`).
  TypeScript взят 6.0, потому что typescript-eslint пока не поддерживает 7.
- Создать проект Vite (`vanilla-ts`), включить `strict`.
- Добавить Vitest, ESLint, Prettier, скрипт `npm run check`.
- `.gitignore`, первый коммит, привязка к GitHub-репозиторию.
- **Результат:** `npm run dev` открывает пустой canvas на весь экран.

## Этап 1. Игровой цикл и ввод ✅
- `requestAnimationFrame` + фиксированный шаг физики с аккумулятором.
- Ввод с клавиатуры: A — поворот против часовой стрелки, D — по часовой
  (маневровые двигатели), W — основная тяга.
- Ввод с мыши: позиция курсора в координатах мира (прицел), ЛКМ — выстрел.
- `Vec2` и тесты к нему.
- Отладочный оверлей: FPS, число объектов (включается клавишей F1).
- **Результат:** на экране тикает счётчик кадров, клавиши выводят состояние.
  Итог: оверлей пока включён по умолчанию (F1 скрывает), клавиши читаются
  по `e.code`, поэтому работают и в русской раскладке. Мировые координаты
  считает `Camera`: центр экрана — точка (0, 0) мира.

## Этап 2. Корабль с инерцией (без гравитации) ✅
- Поворот вокруг оси, тяга вдоль носа, инерция, ограничение максимальной
  скорости (по желанию).
- Отрисовка корабля и пламени двигателя.
- **Результат:** кораблём можно полетать «как в невесомости».
  Итог: интегратор semi-implicit Euler вынесен в `physics/integrator.ts`,
  `Ship.step` принимает внешнее ускорение (туда придёт гравитация).
  Поворот с постоянной угловой скоростью, лимит скорости 600 пикс/с
  (`SHIP_MAX_SPEED`, 0 — без лимита). Пока нет границы поля, улетевший
  корабль показывает стрелка у края экрана, R возвращает его в центр.

## Этап 3. Планета и гравитация ✅
- Планета в центре поля, ускорение `GM / r²` к центру.
- Semi-implicit Euler, тест круговой орбиты (радиус и энергия сохраняются).
- Столкновение корабля с планетой — взрыв или потеря жизни.
- **Фишка:** пунктир предсказанной траектории корабля на N секунд вперёд,
  чтобы было видно, как работает орбита.
- Граница поля для корабля — мягкая: за краем действует слабая
  возвращающая сила, и на экране видно предупреждение.
- **Результат:** можно выйти на орбиту вокруг планеты.
  Итог: гравитация в `physics/gravity.ts`, граница в `physics/boundary.ts`,
  предсказание траектории в `physics/trajectory.ts` (тот же интегратор на
  копии корабля, 10 с вперёд, без учёта тяги, крестик в точке удара).
  Корабль стартует на круговой орбите r = 220 носом по ходу движения.
  При ударе о планету — взрыв и новый корабль через 2 с (жизни будут на
  этапе 6). Поле — круг R = 400 (пока камера без масштаба), за ним
  пружина k·(r − R). В оверлее — высота, перицентр/апоцентр, e, энергия
  и статус орбиты. Клавиша R убрана.

## Этап 4. Метеориты ✅
- Метеорит: позиция, скорость, масса, радиус (зависит от массы), вращение
  спрайта.
- Генерация на краю поля со случайной скоростью и направлением. Часть
  метеоритов идёт по эллипсам, часть пролетает по гиперболам.
- Столкновения метеорита с планетой и с кораблём.
- Поле для метеоритов — круг вокруг планеты: вылетевший за край исчезает.
- **Результат:** вокруг планеты летают метеориты по настоящим орбитам.
  Итог: `Meteor` в `entities/meteor.ts` (радиус r = 6·√m, масса 1–9,
  неровный многоугольник-силуэт, вращение), появление в
  `game/meteorSpawner.ts`: раз в 1,5 с, не больше 2 одновременно, прямо на
  краю поля R = 400. 60 % — эллипсы: точка появления — апоцентр, перицентр
  случайный от 40 до 320 (меньше 60 — упадёт на планету), скорость по
  vis-viva. 40 % — гиперболы: 1,05–1,5 второй космической, курс на планету
  с отклонением до ±0,6 рад. Метеорит, упавший на планету, взрывается;
  задевший корабль разбивает его и разбивается сам; ушедший за край целиком
  исчезает. Метеориты друг с другом пока не сталкиваются. Случайность через
  `core/random.ts` (в тестах генератор с зерном). В оверлее — число
  метеоритов на эллипсах и гиперболах и счётчики событий.

## Этап 5. Стрельба ⬜
- Прицел мышью, независимо от того, куда смотрит нос корабля. Курсор
  рисуется как перекрестие.
- Интерфейс `Weapon` (перезарядка, `fire(ship, aimPoint)` → снаряды),
  чтобы потом легко добавить другие виды оружия.
- Первое оружие — пушка. Снаряд вылетает в сторону прицела со скоростью
  `v_корабля + v_выстрела · направление`, то есть наследует инерцию
  корабля. Дальше на него действует гравитация планеты, поэтому траектория
  изгибается.
- Попадание: метеорит раскалывается на 2–3 осколка (масса делится, импульс
  сохраняется), мелкие осколки исчезают.
- Перезарядка и ограниченное время жизни пули.
- **Результат:** можно сбивать метеориты.

## Идеи на потом
- Несколько планет или луна (задача трёх тел в миниатюре).
- Ограниченное топливо, дозаправка на орбитальной станции.
- Режим «песочница»: запускать метеориты мышью и смотреть на орбиты.
- Поддержка тачскрина и геймпада.

- Новые виды оружия через интерфейс `Weapon`: лазер, ракеты с
  самонаведением, мины на орбите.
- Пунктир предсказанной траектории снаряда от прицела.

## Принятые решения
1. **Границы поля:** для корабля — мягкая граница с возвращающей силой
   и предупреждением, для метеоритов — круг вокруг планеты, за краем они
   исчезают. Телепорта с края на край нет: он ломает орбиты.
2. **Управление:** A / D — поворот против / по часовой стрелке
   (маневровые двигатели), W — тяга, мышь — прицел, ЛКМ — выстрел.
3. **Оружие:** прицел мышью, несколько видов через общий интерфейс.
   В первой версии — пушка, снаряд которой наследует скорость корабля и
   летит в поле гравитации планеты.
